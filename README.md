# zen·dom

A calm household app for Sam and Charlie: chores (Fair Play cards), kitchen (recipes, meal plan, groceries, pantry), family health profiles, notes, calendar and budget.

- `index.html` — the whole app (one file, no build step)
- `tests/run_tests.py` — end-to-end checks in headless Chromium: `python3 tests/run_tests.py index.html`
